# Storybook Walk

Tell me a story. Paint it. Then walk inside.

**Play it:** https://sendtovishnu.github.io/storybook-walk/ · **Source:** https://github.com/sendtovishnu/storybook-walk

A cozy pixel-art game built for the **Delight** track. Claude writes a four-page
children's story from a one-line seed, you paint each page with a tile palette,
then you walk the hero through the scenes you painted while the story narrates
itself and the things you placed whisper little lines written in the story's voice.

Every pixel of art is generated by code at load time. No image assets.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:5173. Works with no API key: a built-in story is used and
props speak generic lines. Click the gear on the title screen to paste an
Anthropic API key (stored only in your browser) and Claude Opus 5 writes a new
story from your seed plus a line for every prop you painted.

## Demo flow

1. Type a seed like *a bear who lost her favourite song*, or click a chip.
2. Read the four pages as they type out, then **Start painting**.
3. Every page opens with a starter sketch: a winding path from the hero's doorstep to the
   right edge, a sparse tree line, a pond if the page calls for water, and a few of the
   props the story suggests. Add to it, erase parts, hit **Sketch again** for a new
   layout, or **Clear** for a blank page. Suggested tiles carry a star.
4. **Walk in**. Arrows or WASD. Walk up to anything you painted to hear it speak.
5. Walk off the right edge to turn the page. Four pages, then The End.

## Build

```bash
npm run build
```

Static output in `dist/`. Drop it on any static host.

## Stack

Vite, Phaser 3 (WebGL, bloom and vignette post-FX, arcade physics, particles),
plain JavaScript, `@anthropic-ai/sdk` in the browser with structured outputs and
the server-side refusal fallback enabled.
